## Task 2: disk-fix (v1.3)

### Problem Discovery
WD Elements 1TB external HDD — worked yesterday after manual fix, lost drive letter again today.

### Diagnosis
```powershell
Get-Disk -Number 1 | Select OperationalStatus, OfflineReason
# OperationalStatus: Offline
# OfflineReason: Policy
```

Root cause: Windows **SAN Policy** default (`OfflineShared`) forcibly takes USB external disks offline. The disk physically connects fine, but Windows logically disconnects it at the policy level.

### Fix
3-in-1 batch script `fix_disk.bat` (requires admin):
1. `diskpart: online disk + assign letter=F` — immediate recovery
2. `diskpart: SAN POLICY=OnlineAll` — permanent policy change
3. `powercfg: disable USB selective suspend` — prevent power-saving disconnects

### Result
- Immediate: Drive F: accessible
- Permanent: SAN policy changed, no more letter loss on reconnect

### Files Produced
- `disk-fix/skill.md`
- `disk-fix/fix_disk.bat`

## Task 3: recycle-fix (v1.4)

### Problem Discovery
Every time F: drive was accessed, Windows popped up "Recycle Bin on F: is corrupted. Empty it?"

### Diagnosis
- Inspected `F:\$Recycle.Bin\`
- Found **60+ SID folders** from different Windows installations (2017-2026)
- One or more `$I` (index) files corrupted
- Cause: cross-machine usage + unsafe ejection over 9 years

### Fix
Single command:
```cmd
rd /s /q F:\$Recycle.Bin
```
No admin required. Windows auto-recreates a fresh Recycle Bin.

### Result
- Prompt eliminated
- Optional: permanently disabled Recycle Bin on F: via Properties
