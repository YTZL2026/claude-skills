# Desktop Organize Skill

智能桌面文件归类整理。扫描桌面所有文件和文件夹，分析内容模式，合并同类项，语义化重命名，保持桌面整洁。

## 触发条件

用户说以下任意一句时调用此技能：
- "整理桌面"
- "桌面太乱了"
- "/desktop-organize"
- "归类文件"
- "桌面清理"
- "帮我收拾桌面"

## 核心方法论：5步归类法

### 1. 扫描
列出桌面所有文件/文件夹，按类型统计：
```bash
ls -1 ~/Desktop/ | grep -v "desktop.ini"
```

### 2. 分类
按文件内容/命名/类型归入大类：

| 类型 | 归属 | 示例 |
|------|------|------|
| Excel/Word/PDF 工作文件 | 按主题归入已有工作文件夹 | `2026康复A区5月份.xlsx` → `病历管理/` |
| 图片/截图 | 暂存待整理或按来源归类 | UUID命名的医疗图片 → `病历管理/患者资料/` |
| 项目文件夹 | 归入工具箱或开发目录 | `meetlove-chest-bot` → `个人创作/AI项目/` |
| PPT/发言稿 | 按主题归入对应项目 | `医保飞检PPT` → `质控管理/医保飞检汇报/` |
| 密钥/配置 | 归入 CC-Toolkit | `GITHUB秘钥.txt` → `CC-Toolkit/` |
| 快捷方式 | 保留不动 | `.lnk` 文件 |
| 他人文件夹 | 保留不动 | `李爽的文件/` |

### 3. 合并
检测与已有文件夹重叠的内容：
- 同名文件夹 → 合并内容（保留最新版本）
- 相同主题散文件 → 归入已有文件夹对应子目录
- 空文件夹 → 删除

### 4. 重命名
语义化命名规范：
- ❌ `数据5.12` → ✅ `专项审计数据`
- ❌ `归档` → ✅ `病历归档`
- ❌ `日常` → ✅ `行政事务`
- ❌ `个人` → ✅ `个人创作`

### 5. 收尾
- 桌面上只保留：快捷方式、工具箱入口、工作台入口、他人文件夹
- 生成 `README.md` 说明新结构
- 删除临时文件（`~$*.docx` 等 Office 临时文件）

## 执行流程

### Phase 1：全盘扫描
```bash
# 桌面文件清单
ls -la ~/Desktop/
# 各文件夹内文件统计
find ~/Desktop/ -maxdepth 3 -type d | sort
```

### Phase 2：内容分析（关键步骤）
**必须深读文件内容才能准确归类**，而非仅看文件名：
```python
# 抽样读取 Excel/Word/PDF 文件内容
# 分析命名模式、日期、科室等关键信息
```

### Phase 3：制定归类方案
向用户展示：
- 发现的问题（散落文件、重复内容、命名不当）
- 归类方案（哪个文件去哪）
- 清理项（哪些可以删）
- **等用户确认后再执行移动**

### Phase 4：执行归类
```bash
# 创建新目录结构
mkdir -p "新路径"
# 移动文件（不是复制）
mv "旧位置" "新位置"
# 清理临时文件
rm "~$*.docx"
```

### Phase 5：验证与文档
- 列出桌面最终状态
- 生成 README.md 导航
- 报告整理前后对比

## 安全原则

- **移动不是删除**：所有文件只是改变位置，不会丢失
- **先确认再执行**：Phase 3 必须用户过目
- **不碰他人文件**：如 `李爽的文件/` 等他人文件夹原封不动
- **保留快捷方式**：`.lnk` 文件不受影响

## 真实案例

2026-06-16 阿莲的桌面整理：
- 整理前：桌面 50+ 个散落文件/文件夹
- 整理后：8 个语义化文件夹，桌面只留快捷方式 + 工具箱 + 工作台
- 合并了 3 处散落的质控材料、2 处重复的病志归档
- 14 张 UUID 命名的病历图片暂存待整理

## 注意事项

- 中文文件名在 bash 下可能编码异常，优先用 PowerShell 或 Python 操作
- Office 临时文件（`~$*`）直接删除
- 桌面上的项目文件（如 `git/`、`linux/`）不轻易移动，除非用户明确要求
- 整理后建议同步到 CC-Toolkit 的说明文档中
