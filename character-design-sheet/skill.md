# 即梦 & 香蕉 角色人设图提示词 Skill

用即梦（Jimeng）3.0/3.1 和香蕉（Banana RPO）生成专业级角色人设图，包含三视图、表情特写和动态姿势。

## 使用方式

用户通过以下方式调用：
- `/character-design-sheet <角色描述>`
- "帮我做一个人设三视图"
- "用即梦出角色设计图"
- "生成角色的正面侧面背面图"
- "香蕉RPO出人设排版"

## 工具选择指南

| 需求 | 推荐工具 |
|------|---------|
| 角色立绘 + 氛围感 | **即梦 3.0 / 3.1** |
| 三视图 + 表情 + 动作排版 | **香蕉 RPO (Banana RPO)** |
| 追求3D游戏CG质感 | 二者均可，都支持 OC 渲染质感 |

---

## 一、即梦 3.0 / 3.1 提示词模板

用于生成**角色正面中景立绘**，强调光影质感和氛围。

### 提示词结构

```
画风 [画风标签]
主体 [角色外观描述]
灯光 [光源配置]
构图 [镜头配置]
```

### 提示词模板（使用时替换方括号内容）

```
画风 3D 游戏CG OC渲染质感
主体 [角色描述：种族/体型/面部特征/装备/服装]，深色纯色背景
灯光 角色面光，45度侧光，边缘光
构图 角色正面中景朝镜头，镜头平视
```

### 即梦常用参数词库

**画风标签：**
3D 游戏CG, OC渲染质感, PBR材质, 手绘插画, 赛博朋克, 奇幻, 写实, 二次元, 水墨风, 厚涂

**灯光配置：**
- 角色面光 (front light)
- 45度侧光 (45° side light)
- 边缘光 (rim light / edge light)
- 轮廓光 (contour light)
- 顶光 (top light)
- 逆光 (backlight)
- 柔光 (soft light)
- 体积光 (volumetric light)

**构图选项：**
- 镜头平视 (eye level)
- 低角度仰视 (low angle)
- 高角度俯视 (high angle)
- 正面中景 (front medium shot)
- 半身像 (half body)
- 全身像 (full body)

## 二、香蕉 RPO (Banana RPO) 提示词模板

用于生成**角色三视图 + 表情 + 动作排版**，输出为三等分排版人设图。

### 提示词结构

```
[排版描述]
人物描述：[角色详细描述]
背景：黑色背景，全身像，视觉冲击力，光影交错
材质：[材质描述]
灯光：[灯光配置]
排版：三等分排版，第一排 三视图，第二排 人物表情，第三排 人物动作
```

### 提示词模板（使用时替换方括号内容）

```
镜头拍摄人物全身三视图（正面侧面背面），四种日常的不同脸部表情特写，四种日常的不同的姿势，3D 游戏CG OC渲染质感
人物描述：[角色种族/体型]，皮肤质感：[皮肤描述]，自然瑕疵。
背景：黑色背景。全身像，视觉冲击力，光影交错，
材质：细节复杂，质感细腻，高细节，3D 游戏CG OC渲染质感
灯光：45度侧光，轮廓光，3D 游戏CG OC渲染质感
排版：三等分排版，第一排，三视图，第二排 人物表情；第三排，人物动作
```

### 香蕉RPO 排版说明

| 排版分区 | 内容 | 数量 |
|---------|------|------|
| 第一排 | 三视图（正面 / 侧面 / 背面） | 3 个视角 |
| 第二排 | 脸部表情特写 | 4 种表情 |
| 第三排 | 人物动态姿势 | 4 种姿势 |

## 完整示例

```

主体 一个成年兽人，强壮身材，脸上血红色符文，手持战斧，深色纯色背景
```

## 可用画风标签速查

| 风格 | 标签组合 |
|------|---------|
| 3D游戏CG | `3D 游戏CG, OC渲染质感, PBR材质, 8k` |
| 赛博朋克 | `Cyberpunk, Neon lights, High contrast, Blade Runner aesthetic` |
| 奇幻 | `Fantasy, Magic glow, Iridescent, Dungeons & Dragons style` |
| 古风 | `Ancient Chinese, Ink wash, Silk texture, Tang Dynasty` |
| 二次元 | `Anime style, Cel shading, 2D illustration, Manga` |
| 写实 | `Photorealistic, Hyper-realistic, 8k, Unreal Engine 5` |
| 暗黑 | `Dark Fantasy, Gothic, Chiaroscuro, Volumetric shadows` |

## 注意事项

1. **即梦 3.0 和 3.1** 的提示词以中文关键词为主，用空格分隔
2. **香蕉 RPO** 也支持中文关键词，排版描述要放在最前面
3. 角色外观描述越具体，出图一致性越高
4. "深色纯色背景" 或 "黑色背景" 有助于突出角色主体
5. 45度侧光 + 边缘光是经典的角色打光组合，能突出立体感
6. 如果需要多角色，分别生成后用排版工具拼接效果更好
