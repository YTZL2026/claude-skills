# 出图补充提示词 Skill

在生成连续分镜图时，补充空间一致性和画面连贯性的核心指令。此 skill 可叠加在其他分镜生成 skill（如 storyboard-9-grid、storyboard-25-grid）之后使用。

## 使用方式

用户通过以下方式调用：
- `/image-consistency-supplement`
- "给这批分镜加一致性约束"
- "确保这几张图的风格统一"
- "补充空间连贯性提示词"

## 核心补充提示词

将此段提示词追加在分镜生成指令的末尾，或作为生成时的额外约束条件：

> 以参考图为主体，注意环境的空间布局，空间中人物与内容物品的相对位置，并生成不同角度的符合剧情发展的连续的连贯性分镜图，注意一定要保持与图片美术风格以及灯光氛围一致，给出图片

## 适用场景

| 场景 | 说明 |
|------|------|
| 多分镜连续生成 | 确保 9 宫格 / 25 宫格各分镜之间风格统一 |
| 角色一致性 | 同一角色在不同分镜中外观一致 |
| 场景空间连续 | 房间布局、物品位置在不同角度下逻辑连贯 |
| 灯光氛围延续 | 同一场景的光源方向、色温、强度保持一致 |
| 剧情时间线 | 连续动作在视觉上平滑过渡 |

## 空间一致性检查清单

在生成前 / 生成后，用以下维度检查：

### 1. 环境空间布局
- [ ] 主要物体的位置是否跨分镜一致？（如：床在中央，门在背景左侧）
- [ ] 人物与物品的相对位置是否合理？
- [ ] 不同角度的摄像机位置是否在同一个物理空间内？

### 2. 美术风格统一
- [ ] 整体画风是否一致？（赛博朋克/古代宫廷/写实/动漫...）
- [ ] 色彩调色板是否统一？
- [ ] 材质渲染质感是否匹配？

### 3. 灯光氛围延续
- [ ] 主光源方向是否一致？
- [ ] 光线色温是否匹配场景设定？
- [ ] 阴影方向和强度是否合理？

### 4. 剧情连贯性
- [ ] 人物动作是否自然过渡？
- [ ] 时间推进是否符合逻辑？
- [ ] 不同角度的镜头是否服务于同一叙事线？

## 与其他 Skill 的配合

本 skill 设计为**叠加层**，在以下场景中追加使用：

```
/storyboard-9-grid [剧本]  →  出9宫格分镜JSON
/image-consistency-supplement  →  在每个prompt后追加空间一致性约束
```

或在生成指令中直接组合：

> 生成 3x3 宫格分镜，每个分镜 20-30 词，以参考图为主体，注意环境的空间布局，空间中人物与内容物品的相对位置，并生成不同角度的符合剧情发展的连续的连贯性分镜图，注意一定要保持与图片美术风格以及灯光氛围一致
